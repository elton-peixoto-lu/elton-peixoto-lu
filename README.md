## About me

I build platform capabilities that make delivery faster, safer, and easier for engineering teams.

- 10+ years in infrastructure and cloud
- 6+ years focused on platform engineering and internal developer platforms
- Strong background in AWS, GCP, Kubernetes, Terraform, Go, observability, governance, and FinOps
- I treat platforms as products: secure by default, automated by design, developer-friendly by principle

## What I work on

```text
Platform Engineering   -> scaffolding, guardrails, golden paths, delivery standards
Cloud Architecture     -> AWS/GCP design, migrations, reliability, cost-aware decisions
Kubernetes             -> EKS, GKE, GitOps, workload identity, zero-downtime rollouts
Governance + FinOps    -> policy-as-code, quotas, tagging, remediation, cloud visibility
Developer Experience   -> reduce cognitive load without reducing engineering autonomy
```

- 🌱 Deepening hands-on work with Workload Identity Federation and keyless CI/CD (GitHub Actions ↔ AWS/GCP)
- ✍️ Writing about platform engineering, cloud governance, and FinOps
- 💬 Ask me about internal developer platforms, Kubernetes multi-tenancy, or cloud cost governance
